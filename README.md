# TypeScript Problem Solving

A collection of TypeScript solutions for coding challenges and algorithm problems.

This repository contains algorithm and problem-solving exercises implemented in TypeScript.

The goal of this project is to practice logical thinking, improve TypeScript skills, and understand common algorithm patterns such as recursion, DFS, greedy algorithms, dynamic programming, and array-based problem solving.

## Problems Solved

### 1. Flood Fill
**Algorithm:** DFS / Recursion

**Description:**
Changes connected cells with the same color starting from a specific position.

---

### 2. Trapping Rain Water
**Algorithm:** Arrays / Math

**Description:**
Calculates how much water can be trapped between bars after raining.

---

### 3. Climbing Stairs
**Algorithm:** Recursion

**Description:**
Calculates how many different ways exist to climb stairs using either 1 step or 2 steps.

---

### 4. Jump Game
**Algorithm:** Greedy Algorithm

**Description:**
Determines whether it is possible to reach the last index of an array.

---

### 5. Rod Cutting
**Algorithm:** Recursion / Dynamic Programming Idea

**Description:**
Determines the maximum profit that can be obtained by cutting a rod into pieces and selling them based on a given price list.

## How to Run

Install dependencies:

```bash
npm install
```

Compile TypeScript:

```bash
npx tsc
```

Run specific problems:

```bash
npm run FloodFill
npm run TrappingRainwater
npm run ClimbingStairs
npm run JumpGame
npm run RodCutting
```
